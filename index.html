About the project

Stellar is an independent personal project by Alex Wolfe. It is not publicly available for download. Features and integrations are being developed and tested in a private alpha.

The Linear integration is designed to use user-authorized OAuth access to read assigned issues and comments, and to make status changes explicitly confirmed by the user. Connecting a workspace remains subject to that workspace’s access policies.
